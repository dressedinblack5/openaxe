# sdk — generated JS API client

## OVERVIEW

Generated TypeScript SDK (`@opencode-ai/sdk`) — openaxe server API client, built from the OpenAPI spec via `@hey-api/openapi-ts`.

## STRUCTURE

```
├── openapi.json          # OpenAPI 3.1 spec (generated by `bun dev generate` from openaxe server)
└── js/
    ├── script/
    │   ├── build.ts      # Codegen pipeline: spec → @hey-api/openapi-ts → tsc compile
    │   └── publish.ts    # npm publish with export path transform (src/ → dist/)
    ├── src/
    │   ├── index.ts      # Re-exports client + server, convenience createOpencode()
    │   ├── client.ts     # Client factory
    │   ├── server.ts     # Server factory (embeddable)
    │   ├── process.ts    # Process utilities
    │   ├── error-interceptor.ts
    │   ├── gen/          # v1 generated code (client, sdk, types, core utilities)
    │   └── v2/           # v2 API layer
    │       ├── client.ts, server.ts, data.ts, index.ts
    │       └── gen/      # v2 generated code (same structure as gen/)
    └── example/example.ts
```

Generated output structure per version (`gen/` and `v2/gen/`):

```
gen/
├── client.gen.ts       # HTTP client (fetch-based, @hey-api/client-fetch)
├── sdk.gen.ts          # OpencodeClient — typed API methods
├── types.gen.ts        # Request/response types
├── client/             # Additional client utilities
└── core/               # pathSerializer, params, auth, bodySerializer, queryKeySerializer, serverSentEvents, utils, types
```

## CONVENTIONS

- **Generated code is read-only.** Edit spec or build script, never hand-edit `gen/` files.
- **Spec source:** `bun dev generate` from the `openaxe` package outputs the OpenAPI JSON. Build falls back to committed `openapi.json` if generation fails (CI guard).
- **SSE type patch:** `build.ts` strips `TError` from `ServerSentEventsResult` generic — `@hey-api/openapi-ts` bug workaround.
- **Export transform:** `publish.ts` rewrites `./src/` paths to `./dist/` in `exports` before publishing.
- **Idempotent publish:** script checks `npm view` before publishing; skips if version exists.
- **Entrypoints:** `"."`, `"./client"`, `"./server"`, `"./v2"`, `"./v2/client"`, `"./v2/server"`, `"./v2/types"`.

## COMMANDS

| Command                   | Action                                          |
| ------------------------- | ----------------------------------------------- |
| `bun run build`           | `bun ./script/build.ts` — full codegen pipeline |
| `bun run typecheck`       | `tsgo --noEmit`                                 |
| `bun ./script/publish.ts` | Pack and publish to npm                         |
